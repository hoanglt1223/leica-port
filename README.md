# Leica camera port, English builds

Patched, English builds of a third-party Leica camera port for Android (package
`com.kobbin.leica.wmrebuild`, version 8.0.0, a HyperOS camera with Leica looks). This repo
holds the scripts that turn the original port APK into these builds, the English
translations, and per-device lens profiles. Ready-made APKs are on the
[Releases](https://github.com/hoanglt1223/leica-port/releases) page.

## Supported phones

| Status | Phones | Build | Evidence |
|---|---|---|---|
| **Tested** | Xiaomi Mi 10T Lite 5G / Redmi Note 9 Pro 5G / Mi 10i (`gauguin`, SM7225) on LineageOS 24 | `leica-gauguin-en-slim.apk`, `leica-gauguin-en.apk` (full) | Photos at 1x, 0.6x, 2x; Pro manual ISO/shutter/WB; M9, M9+, M10-R and film styles; Styles editor; watermark; lens switch 15/15 without freeze; no network traffic |
| **Built, not tested** | vivo iQOO 13 (V2408A, V2408, I2401) | `leica-iqoo13-en.apk` | Static checks only (signature, alignment, manifest, profile JSON). Not yet run on a phone |
| **Built, not tested** | vivo iQOO Neo 11 (V2520A) | `leica-iqooneo11-en.apk` | Static checks only. Not yet run on a phone |
| **Profile in the app, untested** | 261 OPPO, vivo, Redmi and Xiaomi models listed in [device-profiles.md](device-profiles.md) | Any build; the app auto-selects the profile by model code | Profiles come from manufacturer specs in the original app. Nobody in this project has tried them |
| **Unknown** | Everything else | Any build | The app may open only the main camera, or not start. Request a profile (below) |

Notes:

- `leica-gauguin-en.apk` is the full gauguin build: the same fixes and film styles as the
  slim build, plus every model and DSP file (525 MB). Tested on gauguin (photos at
  0.6x/1x/2x, film styles, no crash, no notification). The slim build is smaller and is
  enough for gauguin.
- Every build contains the 261 built-in profiles plus the profile of its own target phone
  (gauguin, iQOO 13 or iQOO Neo 11). The gauguin slim build lacks the DSP files that HTP phones use, so on a
  Snapdragon 8 Elite phone use an iQOO build.
- Leica styles use the Qualcomm Hexagon DSP where available and fall back to CPU / ONNX
  Runtime / LUT elsewhere (slower, tens of seconds per photo). MediaTek and Exynos phones
  only get the fallback.
- Whether the ultrawide or tele lens works depends on the phone's camera HAL letting a
  third-party app open it.

## Install

1. **Uninstall every other build of `com.kobbin.leica.wmrebuild` first**, including the
   original port. Our builds are signed with a different key, so Android refuses to update
   over another build. Uninstalling deletes the app's settings.
   ```
   adb uninstall com.kobbin.leica.wmrebuild
   ```
2. Download the APK for your phone from Releases and check it against `SHA256SUMS`.
3. Install with `adb install <file>.apk` or a file manager (allow installs from unknown
   sources; on OriginOS / Funtouch / HyperOS you may need to turn off the install security
   check).
4. Grant Camera, Microphone, Location (watermark), Photos and Notifications.
5. Allow background activity / no battery restriction for the app, or the system may kill
   the background renderer and keep only the unprocessed photo.
6. On first launch the app copies about 100 MB of models; wait before shooting.

## Request a new device

Open an issue with:

- phone name and model code (`adb shell getprop ro.product.model`),
- `adb shell getprop ro.product.device` and `adb shell getprop ro.soc.model`,
- the camera dump as an attached file:
  ```
  adb shell dumpsys media.camera > camera.txt
  ```
- which lenses the stock camera offers (0.6x, 1x, 2x, 3x...).

The camera dump gives lens IDs, sensor sizes and focal lengths, which is what a profile needs.

## Known issues

- Rear camera only: no front camera, video, portrait or night mode. The port exposes Pro,
  Leica Essential and Leica Styles.
- No RAW/DNG in Pro mode (JPG/HEIF only).
- Film styles: the preview shows the M9 tone; the LUT is applied to the saved photo.
- iQOO 13: no 4x/5x chip (the profile schema has no crop stop on the tele); digital zoom
  still works.
- The watermark frame shows the phone name from the original watermark config, not your
  phone.
- The porter's author dialog stays in its original language (the tool that translates it is
  not published because it contains the app's key).
- APKs are large (420-555 MB).

## Build from source

You need the original port APK (`com.kobbin.leica.wmrebuild` 8.0.0); it is not distributed
here. Tools: Java 17 (`javac`), Python 3 with Pillow, the Android SDK (a platform
`android.jar`, build-tools with zipalign, apksigner, aapt2, d8) and smali/baksmali 2.5.2
jars in `tools/bin/`.

```powershell
# gauguin, slim
powershell -ExecutionPolicy Bypass -File scripts\build-leica-gauguin.ps1 -Apk <original.apk> -Slim
# iQOO 13 / iQOO Neo 11
powershell -ExecutionPolicy Bypass -File scripts\build-leica-gauguin.ps1 -Apk <original.apk> -Target iqoo13
```

Output goes to `out/`. The script signs with a test key it creates in `keys/` on first run
(never commit it). To add a phone, write `scripts/<name>-profile.json` in the same shape as
the existing ones and add it to the `-Target` list.

nhận profile máy, sửa treo khi đổi ống kính, sửa thông báo "background rendering" không tự

  ([device-profiles.md](device-profiles.md)).

kiểm tra SHA256SUMS rồi cài. Muốn thêm máy: mở issue, đính kèm file
`adb shell dumpsys media.camera > camera.txt` và mã máy.
